# SDL2 Breakout

C++ and SDL2 clone of breakout - [source](<https://en.wikipedia.org/wiki/Breakout_(video_game)>).

The purpose of this project is to get experience in C++ and game development.

Requirements:

- SDL2 (just install with your local package manager).
  - I used [Homebrew](https://brew.sh/)

The game is written on a M4 Macbook Pro
